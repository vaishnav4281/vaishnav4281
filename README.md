## 🚀 Featured Project

### 🔍 DomainScope

**Domain & Infrastructure Intelligence Platform**

A cloud-native platform for collecting and analyzing **domain, DNS, IP, and infrastructure signals**, built with a strong emphasis on **performance, scalability, and clean architecture**.

**Why it matters**

* Asynchronous, queue-based scanning pipeline
* Redis-backed caching for high throughput
* Rate-limited & abuse-resistant APIs
* Designed with real-world constraints in mind

**Core Capabilities**

* DNS & extended DNS analysis
* ASN & hosting intelligence
* SPF / DKIM / DMARC validation
* SSL / TLS inspection
* IP reputation & proxy/VPN detection

**Stack**

* Node.js, TypeScript, Express
* PostgreSQL, Prisma, Redis
* BullMQ, background workers

🔗 [https://github.com/vaishnav4281/Domainscope](https://github.com/vaishnav4281/Domainscope)
